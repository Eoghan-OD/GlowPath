What Is GlowPath?

GlowPath is a health and fitness tracking application designed around simplicity and accessibility. Built using Agile methodology, it allows users to input workouts, visualize progress, and receive insights without the clutter of complex commercial apps.

Core Features

  • 📝 Easy Data Entry: Log workouts manually in a few seconds.
  • 📂 CSV Uploads: Import activity data quickly from files.
  • 📊 Progress Visualisation: (Sprint 2) Track your performance with charts.
  • 🤖 Smart Insights: (Sprint 3) Receive personal feedback and trends.
  • 💾 Data Persistence: Saved automatically in local storage.

Our Mission

The GlowPath team aims to create a project that demonstrates Agile collaboration and technical skill. Every sprint builds upon the last, moving from data input to visualization and finally to intelligent insights.
